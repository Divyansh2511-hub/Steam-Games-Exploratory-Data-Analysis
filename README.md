# Steam-Games-Exploratory-Data-Analysis
## Overview

This project performs Exploratory Data Analysis (EDA) on a Steam Games dataset using Python. The objective is to understand trends in game releases, genres, pricing, review scores, and player engagement through data cleaning, feature engineering, and visualization.
The project demonstrates the complete EDA workflow, from loading and preprocessing the dataset to generating meaningful insights using statistical summaries and visualizations.

## Project Objectives

- Understand the dataset structure.
- Clean and preprocess the data.
- Perform feature engineering.
- Analyze release trends.
- Explore genre distribution.
- Study pricing patterns.
- Analyze review scores.
- Investigate player engagement.
- Visualize insights using charts.

## Dataset

**Source:** Kaggle
**Features**
- AppID
- Name
- Release Date
- Primary Genre
- Price
- Review Score
- Total Reviews
- Estimated Owners
- Steam Deck Status
- Peak Players

## Key Insights

- Steam has experienced significant growth in game releases over the years.
- Action and Indie are among the most common genres.
- Most games are priced in the lower price range.
- Higher prices do not necessarily correspond to higher review scores.
- A small number of games account for the highest player engagement.
